# Snake Games

### [Standard Example](https://gafum.github.io/snake-games/)

This repository shows the same Snake game in different programming languages.

Each folder contains a simple version of the Snake game.

- `web/` contains the JavaScript browser version.
- `C/` contains the console version written in C.

How to use:

- Open `web/` and read `web/README.md` to run the JavaScript version.
- Open `C/` and read `C/README.md` to compile and run the C version.

This project is for learning and comparing simple game implementations in different languages.
