# Snake Game in C

This folder contains a simple Snake game written in C for the console.

How to run:

1. Open a command prompt in the `C` folder.
2. Compile the code:

```bash
gcc snake.c -o snake.exe
```

3. Run the game:

```bash
snake.exe
```

Controls:

- Use the arrow keys to move the snake.
- Press `q` to quit.

Note:

This version is designed for the Windows console. If you do not have `gcc`, install MinGW or another C compiler.
